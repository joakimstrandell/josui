# @josui/tokens-preview

Preview Tailwind CSS tokens in the browser with live reload.

## What's inside

```bash
npx @josui/tokens-preview --input path/to/tokens.css
```

Opens a browser showing every design token in the given CSS file — color scales,
typography, spacing, and more — grouped and rendered agnostic to token names.
Edits to the source file hot-reload the preview.
